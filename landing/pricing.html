FAQ

Questions, answered

Does GreenSecOps ever store my source code?

No. GreenSecOps reads workflow files (.github/workflows/*.yml) via the GitHub API using the permissions you grant. Your application source code is never requested, downloaded, or stored — only the content of those workflow files, along with the resulting analysis record, is persisted in our database.

How does billing work? Can I cancel at any time?

Subscriptions are billed monthly via Stripe and renew automatically. You can cancel at any time from the billing page. When you cancel, your plan remains active until the end of the current billing period and then downgrades to Free. We do not offer prorated refunds for partial months, but we will consider refund requests for exceptional circumstances — contact $ { SUPPORT_EMAIL}.

What counts as an "analysis"?

One analysis corresponds to one workflow file being graded. If a push changes three workflow files, that consumes three analyses. If the file content is identical to the previous analysis (same SHA), the cached result is returned and no quota is consumed.

What AI model is used for fixes?

GreenSecOps uses frontier large language models (including OpenAI GPT-4 and Anthropic Claude) to generate fix suggestions. The specific model is chosen based on the issue category and complexity. You always review the proposed patch before it is committed to any pull request.

How do I qualify for the Open Source plan?

Your project must be publicly hosted on GitHub under an OSI-approved open-source licence, actively maintained (at least one commit in the past 90 days), and not commercially backed in a way that makes it ineligible for free-tier benefits. We review applications within 5 business days.

Do you offer annual billing or volume discounts?

Annual billing and volume pricing for very large organisations are available — contact $ { SALES_EMAIL} to discuss your needs.

Which GitHub plans are supported?

GreenSecOps works with all GitHub plans — Free, Pro, Teams, and Enterprise Cloud. We use the public GitHub Apps API and standard OAuth; no GitHub Enterprise Server support at this time.
